# 🚀 Momentum – AI-Powered Personal Productivity & Habit Tracking Platform

**Momentum** is an intelligent, modern productivity platform designed to help users build consistent habits, plan daily schedules, track goal progress, monitor activity time, and maintain daily reflection journals. Integrated with AI, Momentum delivers personalized insights, performance heatmaps, and automated weekly/monthly reviews to help users maintain momentum and achieve personal & professional growth.

---

## ✨ Features

- 📅 **Daily Schedule & Time Planner**: Plan tasks, track start/end times, and monitor daily progress.
- ⚡ **Habit Tracker**: Build habits, set custom goals, track streaks, and visualize completion rates.
- 🎯 **Goal Management**: Define long-term targets and track month-by-month completion percentages.
- ⏱️ **Quick Activity Logging & Analytics**: Log time spent across categories (Sports, DSA Practice, Reading, Work) with heatmaps and breakdown charts.
- 📝 **Daily Reflection Journal**: Reflect on growth, record notes, and track daily mood.
- 🤖 **AI Coaching & Reviews**: Automated weekly/monthly summaries, personalized tips, and progress reports generated by AI.

---

## 🛠️ Tech Stack

### Frontend (`/client`)
- **Framework**: React (Vite)
- **Language**: TypeScript
- **Styling**: Modern CSS / Glassmorphism UI

### Backend (`/server`)
- **Runtime**: Node.js (ES Modules)
- **Framework**: Express.js
- **Database**: PostgreSQL
- **ORM**: Prisma ORM
- **Authentication**: JWT (JSON Web Tokens)

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/)
- [PostgreSQL](https://www.postgresql.org/) database server running locally or hosted

---

### 1. Backend Setup (`server/`)

1. **Navigate to the server directory**:
   ```bash
   cd server
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Update `server/.env` with your PostgreSQL database credentials:
   ```env
   DATABASE_URL="postgresql://username:password@localhost:5432/momentum"
   JWT_SECRET="your_secret_key"
   PORT=5000
   ```

4. **Initialize / Generate Prisma Client**:
   ```bash
   npx prisma generate
   ```

5. **Start the Backend Server**:
   - **Development mode** (auto-reload with nodemon):
     ```bash
     npm run dev
     ```
   - **Production mode**:
     ```bash
     npm start
     ```

The API will be available at `http://localhost:5000/`.

---

### 2. Frontend Setup (`client/`)

1. **Navigate to the client directory**:
   ```bash
   cd client
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the Development Server**:
   ```bash
   npm run dev
   ```

The application will run at `http://localhost:5173/` (or the port specified by Vite).
